title: Volcano plot from DESeq2 results
language: R
summary: Turns a DESeq2 results table into a labelled volcano plot, with the thresholds and colours set in one block at the top.

A starting point rather than a finished figure. It takes the data frame that
`DESeq2::results()` gives you, applies a fold-change and adjusted-p cutoff,
labels the genes furthest out in each direction, and writes a PDF sized for a
single-column figure.

Everything you are likely to want to change — the cutoffs, how many genes are
labelled, the colours, the output size — sits in the settings block at the top,
so the rest can usually be left alone.

## Requirements

R — 4.2 or newer
ggplot2 — draws the plot
ggrepel — keeps the gene labels from sitting on top of each other

## The columns it expects

log2FoldChange — as named by DESeq2
padj — the adjusted p-value, also as named by DESeq2
gene — the gene name, or the table's row names if there is no such column

An edgeR or limma table works once those three are named to match.

## How to run it

Install the two packages, if you have not already:

```r
install.packages(c("ggplot2", "ggrepel"))
```

Export your results and run the script beside them:

```r
write.csv(as.data.frame(res), "results.csv")
```

```sh
Rscript volcano_plot.R
```

It writes `volcano.pdf` into the same folder and prints how many genes passed
the cutoff in each direction. To point it at a different file, change
`input_file` at the top.
